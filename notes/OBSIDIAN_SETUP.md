# Obsidian + Longform + Dataview Setup

This repository is already plain Markdown, so it can be opened directly as an Obsidian vault.

Recommended community plugins:
- **Longform** — scene ordering, drafts, word-count goals and manuscript compilation.
- **Dataview** — query YAML metadata across chapter and reference files.

Suggested views to build in Dataview:
- Chapters by act and status.
- Chapters containing each clue ID.
- Chapters containing each red-herring ID.
- Chapters by romance beat.
- Drafted vs outline chapters.
- Word targets by act.

The repository remains canonical even if Obsidian is not used.
