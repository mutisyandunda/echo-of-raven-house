# Writing Workflow

For each chapter:
1. Read the chapter outline.
2. Check `continuity/CHARACTER_KNOWLEDGE.md`.
3. Check clue IDs against `mystery/CLUE_LEDGER.md`.
4. Draft the chapter.
5. Update character/object/clue trackers if prose introduces anything new.
6. Run `python tools/continuity_check.py`.
7. Run Vale / proselint / LanguageTool during revision, not during first-draft flow.
8. Commit with a message that describes story change, not “updates”.

Suggested commit style:
- `Draft chapter 01 arrival and dimension clue`
- `Clarify Eleanor clue timing`
- `Revise Adrian hiring-motive reveal`
- `Resolve west stair continuity`
